# 📱 تطبيق "حاسبتي" - النظام المتكامل لحساب مبيعات كروت الشبكة وإدارة الديون والمشتريات

تطبيق **"حاسبتي"** هو نظام محاسبي وإداري متكامل ومصمم خصيصاً لموزعي وأصحاب شبكات الإنترنت الميكروتك واللاسلكية (مثل **شبكة الدحشة**). يهدف التطبيق إلى أتمتة وتسهيل عمليات بيع كروت الشبكة بمختلف فئاتها، متابعة حسابات البقالات والعملاء بالآجل، إدارة المشتريات من الوكلاء والموردين، وتوليد تقارير مالية وسندات واصل وفواتير حرارية احترافية.

---

## 📋 دليل الاستخدام خطوة بخطوة والتفاصيل الكاملة

### 1️⃣ الآلة الحاسبة العادية (`Regular Calculator`)
تُستخدم لحساب مبيعات الكروت بأسعار التجزئة أو الأسعار القياسية المعتمدة للشبكة.

- **فئات الكروت المتاحة default:**
  - فئة **100** ريال (السعر الافتراضي: 85 ريال)
  - فئة **200** ريال (السعر الافتراضي: 170 ريال)
  - فئة **250** ريال (السعر الافتراضي: 210 ريال)
  - فئة **300** ريال (السعر الافتراضي: 260 ريال)
  - فئة **500** ريال (السعر الافتراضي: 420 ريال)

- **خطوات إجراء عملية بيع:**
  1. ادخل إلى تبويب **"الحاسبة العادية"**.
  2. قم بتحديد كمية الكروت المطلوبة لكل فئة باستخدام أزرار الزيادة والنقصان (`+` و `-`) أو بإدخال الرقم مباشرة داخل المربع.
  3. يظهر الإجمالي الكلي تلقائياً وفي الوقت الفعلي أسفل الشاشة.
  4. اختر طريقة الدفع:
     - **نقد (كاش):** يتم تسليم المبلغ كاملاً واستلامه فوراً.
     - **آجل (دين):** يتطلب اختيار اسم البقالة أو المحل المشتري.
  5. في حالة البيع بالآجل:
     - اختر البقالة من القائمة المنسدلة، أو أضف بقالة جديدة بضغطة زر.
     - أدخل **المبلغ الواصل (المدفوع)** إن وجد، وسيقوم التطبيق بحساب **المبلغ المتبقي** وتثبيته كدين على البقالة تلقائياً.
  6. اضغط على **"حفظ وإصدار الفاتورة"**:
     - يتم حفظ العملية في السجل المحلي والمزامنة مع السحابة.
     - يعزف التطبيق نغمة تأكيد نجاح العملية.
     - تظهر خيارات الطباعة (طباعة حرارية Thermal أو PDF A4) والمشاركة الفورية عبر **واتساب** أو **SMS**.

### 2️⃣ الآلة الحاسبة الاحترافية للجملة (`Pro Calculator`)
تُستخدم لبيع الكروت لكبار الموزعين والبقالات ذات سحب الجملة بأسعار تفضيلية مخفضة.

- **الفرق عن الحاسبة العادية:**
  - تمتلك جدول أسعار مستقل يمكن تخصيصه لكل فئة كارت من قسم الإعدادات.
  - تفصل إحصائيات مبيعات الجملة عن المبيعات العادية في التقارير اليومية والشهرية.

---

### 3️⃣ إدارة البقالات والديون (`Shops & Debts`)
قسم مخصص لمتابعة جميع العملاء والبقالات المسجلة وشراء بالآجل.

- **المميزات والخطوات:**
  - **إضافة بقالة جديدة:** إدخال اسم البقالة، رقم الهاتف، الرصيد الافتتاحي (إن وجد)، وتحديد رمزي تعبيري (Emoji).
  - **البحث والتصفية:** إمكانية البحث السريع باسم البقالة، أو تفعيل خيار **"عرض المديونين فقط"**.
  - **حد الأمان للمديونية (Balance Limit):** يمكنك ضبط حد أقصى لمديونية البقالة (مثلاً: 50,000 ريال)، وإذا تجاوزت البقالة هذا الحد تظهر إشارات تحذيرية باللون الأحمر.
  - **إضافة واصل مالي فوري (Quick Payment):**
    - اضغط على زر **"إضافة واصل فوري"**.
    - اختر البقالة، أدخل المبلغ المسدد والبيان/الملاحظات.
    - يتم خصم المبلغ فوراً من دين البقالة وتوليد **سند واصل (Receipt Voucher)** حراري أو PDF تلقائياً مع خيار إرساله عبر الواتساب.
  - **كشف حساب تفصيلي:**
    - عند النقر على أي بقالة، يفتح كشف حساب كامل يضم جميع المبيعات والسدادات السابقة بالتاريخ والوقت والتفاصيل.
    - إمكانية تعديل أو حذف أي عملية مع إعادة إحتساب الرصيد التلقائي.
    - تصدير كشف الحساب كملف PDF مطبوع باسم الشبكة.

---

### 4️⃣ قسم المشتريات والوكلاء (`Purchases & Agents`)
يسمح لصاحب الشبكة بتسجيل وتتبع مشترياته من الكروت من الوكلاء والموردين الأساسيين.

- **الخطوات:**
  1. تسجيل حساب المورد/الوكيل (مثل: شركة الاتصالات، الوكيل الرئيسي).
  2. تسجيل فواتير شراء الكروت بالجملة (كميات وأسعار الشراء).
  3. تسجيل الدفعات المالية المسددة للوكيل.
  4. متابعة صافي المديونية المتبقية للوكيل بحساب آلي دقيق.

---

### 5️⃣ التقارير والإحصائيات المالية (`Reports & Analytics`)
شاشة تحليلية شاملة لأداء الشبكة المالي خلال أي فترة زمنية.

- **محتويات التقارير:**
  - **إجمالي المبيعات الإجمالية واليومية.**
  - **إجمالي الأرباح الصافية.**
  - **تفنيط المبيعات حسب الفئات:** عدد الكروت المباعة من فئة 100، 200، 250، 300، 500.
  - **رسوم بيانية تفاعلية (Recharts):** توضح منحنى المبيعات وتوزيع الأرباح بوضوح visual.
  - **التصدير:** تصدير التقرير المالي كاملاً بصيغة **Excel (.xlsx)** أو **PDF**.

---

### 6️⃣ التخزين والنسخ الاحتياطي المحلي (`Local Storage & Offline Backup`)
- **العمل دون إنترنت (100% Offline):** يعمل التطبيق بكفاءة كاملة ومستقلة تماماً بدون الحاجة لأي اتصال بالإنترنت أو خوادم خارجية، حيث تُحفظ كافة الحسابات والفواتير والديون محلياً وفي أمان تام داخل جهازك (LocalStorage + IndexedDB).
- **النسخ الاحتياطي التلقائي للأنشطة:** يُنشئ التطبيق تلقائياً نسخاً احتياطية بصيغة JSON ويحفظها في مجلد المستندات بالهاتف (Krot).
- **الاسترجاع والتصدير اليدوي:** إمكانية تصدير واسترجاع ملف كامل للبيانات بضغطة زر بصيغة JSON في أي وقت.

---

### 7️⃣ إعدادات الطباعة وشعار الفاتورة (`Settings & Printing`)
- **تخصيص الفاتورة:** إدخال اسم الشبكة (مثلاً: شبكة الدحشة)، اسم الموزع، رقم التواصل، والملاحظة المكتوبة بأفل الفاتورة.
- **خيارات الطباعة:** دعم الطابعات الحرارية الشائعة (Thermal Bluetooth/USB Printers 58mm/80mm) وكذلك طابعات الورق العادي A4/A5.

## 🛠️ آلية العمل التقنية والمعمارية (Architecture & Tech Stack)

| المكون | التقنية المستعملة |
| :--- | :--- |
| **واجهة المستخدم (UI)** | React 18 + TypeScript + Vite |
| **التنسيق والتصميم** | Tailwind CSS (مع دعم الوضع المظلم والنهاري بالكامل RTL) |
| **الحركات والمؤثرات** | Motion (Framer Motion) |
| **الأيقونات** | Lucide React Icons |
| **الرسوم البيانية** | Recharts Data Visualization |
| **التخزين وقواعد البيانات** | Local Storage محلي + النسخ الاحتياطي الذكي تلقائياً (JSON) |
| **التصدير والطباعة** | jsPDF + ExcelJS (XLSX) |
